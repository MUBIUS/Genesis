System Design & Specifications

Genesis Architecture & Implementation Details

Comprehensive breakdown of how Genesis implements Bitcoin Core specifications in pure Python.

1. Cryptographic Primitive Layer

Implements finite field arithmetic modulo the secp256k1 prime \(p = 2^{256} - 2^{32} - 977\). Points on the curve satisfy \(y^2 = x^3 + 7 \pmod p\).

  • FieldElement: Modular addition, subtraction, multiplication, and inverse using Fermat's Little Theorem.
  • Point: Group law operations (point doubling, distinct point addition, point at infinity).
  • ECDSA Signatures: Deterministic nonce generation (RFC 6979) and DER encoding.
  • Base58Check: Checksummed encoding preventing transcription typos in Bitcoin addresses.

2. Block Header & Consensus

Every block header is strictly 80 bytes, matching Bitcoin’s canonical binary wire format.

  • Version (4 bytes): Block version integer.
  • Previous Block Hash (32 bytes): Little-endian double-SHA256 pointer.
  • Merkle Root (32 bytes): Cryptographic root of all included transactions.
  • Timestamp (4 bytes): Unix epoch time.
  • Bits / Target (4 bytes): Compact exponent-mantissa difficulty representation.
  • Nonce (4 bytes): Mining counter incremented during proof of work.

3. UTXO Model & Transactions

Unlike account-based ledgers (e.g. Ethereum), Genesis tracks ownership via an unspent transaction output (UTXO) pool.

  • Coinbase Transactions: Special first transaction per block creating 50 new BTC + transaction fees with no prior inputs.
  • TxIn & TxOut: Inputs reference previous output hashes and output indices; outputs specify satoshis and locking scripts.
  • Double-Spend Prevention: Strict UTXO lookup prevents reusing consumed outputs.

4. Peer-to-Peer Networking

A multi-node TCP gossip layer enables decentralized synchronization.

  • NetworkEnvelope: Binary packet wrapper containing magic bytes, command name, payload length, and checksum.
  • SyncManager: Handles block downloads, chain reorganization (longest valid chain rule), and mempool propagation.
  • Port Binding: Multi-process architecture running mining, networking, and the web UI concurrently.
