# Genesis — Blockchain Core & Node Backend

This directory contains the Python core implementation of the Genesis Bitcoin blockchain, including the consensus engine, P2P sync networking, cryptographic modules, and the Flask block explorer.

For comprehensive documentation, architecture diagrams, installation instructions, and the interactive web demo, please refer to the primary repository [README.md](../README.md).

### Quickstart

To run the Block Explorer from the project root:
```bash
python main.py
```

To run the automated test suite:
```bash
python main.py --test
```

To generate a new keypair and Bitcoin address:
```bash
python main.py --account
```
