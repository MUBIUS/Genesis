What's Implemented

🔐

secp256k1 ECDSA

Bitcoin's elliptic curve — private keys, public key derivation, DER-encoded signatures, and signature verification built from field arithmetic.

⛏️

SHA-256 Proof of Work

Double-SHA-256 mining loop with difficulty adjustment every 10 blocks, targeting a 20-second average block time.

💸

P2PKH Transactions

Pay-to-Public-Key-Hash scripts, coinbase transactions, UTXO set management, fee calculation, and double-spend detection.

🌐

P2P Sync Layer

TCP socket-based peer-to-peer networking with block propagation, chain sync, mempool relay, and orphan chain resolution.

🔗

Merkle Tree

Merkle root computation for all block transactions, identical to Bitcoin's construction.

📦

Block Explorer

Real-time Flask block explorer — browse blocks, transactions, mempool, and addresses with QR codes.
